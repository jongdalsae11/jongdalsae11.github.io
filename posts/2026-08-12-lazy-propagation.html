느리게 갱신되는 구간 트리 노트

2026.08.12 세그먼트 트리 lazy

구간 갱신을 매번 내려가며 처리하면 최악의 경우 $O(N)$이 든다. 갱신을 노드에 "미뤄 두었다가" 필요할 때만 자식으로 내려보내면 질의와 갱신 모두 $O(\log N)$이 된다.이 아이디어를 처음 봤을 때는 게으른 게 어떻게 더 빠른지 납득이 안 갔다.

내려보내기

핵심은 push_down 한 함수다. 노드에 쌓인 지연값을 자식에게 전달하고 자신은 비운다.

void push_down(int node, int l, int r) {
    if (!lazy[node]) return;
    int mid = (l + r) / 2;
    apply(node * 2,     l,       mid, lazy[node]);
    apply(node * 2 + 1, mid + 1, r,   lazy[node]);
    lazy[node] = 0;
}

자세한 배경은 4장에 정리되어 있다.
