데이터의 무손실 압축

2026.08.31 압축

데이터를 압축하는 방법에 대해 알아보자. 데이터를 압축하는 방법에는 무엇이 있을까. 예를들어 AAAAAAAAAA 을 10A로 표현하는 압축이 있겠다. 그렇다면 ABCABCABC와 같은 예시에 대해서는 1A1B1C....와 같이 오히려 데이터가 늘어나는 경우가 존재한다. 그래서 압축 방식은 매우 중요하다.

압축의 종류에는 무엇이 있을까? 크게 손실 압축과 무손실 압축이 있을 것이다. 무손실 압축의 경우는 데이터 자체를 그대로 보존해야하는, 실행파일 등에서 사용된다. 손실 압축은 이미지같이 별로 데이터가 소실되어도 지장이 없는 파일에 대해 사용한다.

이 글에서는 그 중 무손실 압축의 방식에 대해 다룬다.

Run Length Encoding

위에서 들었던 예시와 같이, RLE는 연속된 데이터가 많을때 아주 효과적이다. 그래서 이는 흑백사진(WB)에서 많이 사용된다. 예시를 통해 알아보자.

먼저 흑백 이미지의 역할을 하는 파일을 생성하는 코드를 보자.

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
char str[32768];

int main(){
  int n = 10000;
  FILE *out = fopen("rletext.txt", "w");
  for (int i = 1; i <= n; i++) str[i] = 'W';
  srand((int)time(NULL));
  for (int i = 1; i <= n / 10; i++){
    int c = rand() % n;
    str[c] = (str[c] == 'W' ? 'B' : 'W'); // W <-> B 전환
  }
  for (int i = 1; i <= n; i++)
    fprintf(out, "%c", str[i]);
  fclose(out);
  return 0;
}

수업시간에 배웠던 파일 관리를 이용해 오직 W,B로만 채워진 10000자의 어느정도 연속성이 보장된 문자열을 만든다.사실 왜 모듈러를 쓰지 않았는지는 나도 모르겠다

이제 인코딩 과정을 보자.

#include <stdio.h>
char str[32768];
int n;
int main(){
  FILE *in = fopen("rletext.txt", "r");
  FILE *out = fopen("rleencoded.txt", "w");
  while (!feof(in)) fscanf(in, "%c", &str[n++]);
  n--;  
  for (int i = 0; i < n; i++){
    int cnt = 1;
    while (str[i] == str[i + 1] && i + 1 < n){
      cnt++;
      i++;
    }
    fprintf(out, "%d%c", cnt, str[i]);
  }
  fclose(in);
  fclose(out);
  return 0;
}

한눈에 들어오는 직관적인 알고리즘이다. 원본 텍스트를 스택 내의 str배열에 옮긴 뒤, 연속하는 수를 세고, 연속이 끊기면 개수+문자를 출력시키는 코드이다.

이 방식은 무손실 압축이므로, 원상 복구할 디코딩 코드도 존재한다.

#include <stdio.h>
int n, nc;
char str[32768];
int main(){
  FILE *in = fopen("rleencoded.txt", "r");
  FILE *out = fopen("rledecoded.txt", "w");
  while (!feof(in)) fscanf(in, "%c", &str[n++]);
  n--;  
  for (int i = 0; i < n; i++){
    int cnt = str[i] - '0';
    while (str[i + 1] >= '0' && str[i + 1] <= '9' && i + 1 < n){
      cnt = cnt * 10 + (str[i + 1] - '0');
      i++;
    }
    for (int j = 1; j <= cnt; j++) fprintf(out, "%c", str[i + 1]);
    i++;
  }
  fclose(in); fclose(out);
  return 0;
}

인코딩과 같은 방식으로 스택의 배열에 파일내용을 복사한다.

이제 메인 로직을 살펴보자. cnt에 str[i]의 숫자값일단 숫자인지 아닌진 모르지만, 맨 처음 문자가 숫자임은 자명하다을 대입한다. 그리고, 숫자의 끝까지 돌면서 뒷자리를 채우고 왼쪽으로 10진 시프팅하는 연산을 통해 원본의 문자열 개수를 알아낼 수 있다. 그렇게 된다면, 개수만큼 문자를 출력하고, 그 다음 숫자+문자에 대해 이를 반복하면 RLE 디코딩을 완성할 수 있다.

Lempel-Ziv-Welch(LZW)

RLE가 연속된 문자에 강한 압축 방식이었다면, LZW는 반복되는 문자열 패턴을 사전(dictionary)에 등록해가며 압축하는 방식이다. 흔히 사전 기반 압축이라고 부르는데, 특이한 점은 압축을 시작하기 전에 완성된 사전을 미리 만들어두는 것이 아니라 압축을 진행하면서 사전을 그때그때 동적으로 확장해나간다는 것이다. 원리를 간단히 말하면, 입력을 앞에서부터 읽어가며 지금까지 이어붙인 문자열이 이미 사전에 존재하는 동안은 계속 문자를 이어붙이고, 사전에 없는 문자열이 나오는 순간 그 직전까지의 문자열을 코드 하나로 출력한 뒤 새로 만난 문자열을 사전에 추가한다. 같은 패턴이 반복될수록 하나의 코드가 담당하는 문자열이 점점 길어지기 때문에, 반복이 많은 데이터일수록 압축률이 좋아진다.

이제 인코딩 코드를 살펴보자.

#include <iostream>
#include <fstream>
#include <string>
#include <map>
using namespace std;

map<string, int> endic;     // 압축을 위한 문자열 → 코드 사전
map<int, string> dedic;     // 복원을 위한 코드 → 문자열 사전
int dcnt;                            // 사전에 등록된 항목의 개수
int basic_dcnt;                  // 기본(단일 문자) 사전 개수
int enc[10000], ecnt;        // 압축 코드 저장 배열과 코드 개수

int main(){
    ifstream in("lzwtext.txt");                 // 입력 파일
    ofstream out("lzwencoded.txt");      // 출력 파일
    dcnt = 1;
    char c;
    while(in.get(c)){     // 문자 단위의 기본 사전 생성
        string s = "";
        s += c;
        if(endic.find(s) != endic.end()) // 이미 사전에 존재하는 문자이면 건너뜀
            continue;
        // 새로운 문자를 사전에 등록
        endic.insert({s, dcnt});
        dedic.insert({dcnt, s});
        dcnt++;
    }
    basic_dcnt = dcnt - 1;   // 기본 사전 개수
    in.close();

    // 입력 파일을 처음부터 다시 읽기 위해 재오픈
    in.open("lzwtext.txt");
    ecnt = 1;
    string s = "";

    while(in.get(c)){     // 단어 사전을 확장하며 압축 수행
        // 현재 문자열 s 뒤에 c를 붙인 문자열이 사전에 존재하는 경우
        if(endic.find(s + c) != endic.end())
            s += c;
        // s+c가 사전에 존재하지 않는 경우
        else {
            // 현재 문자열 s의 코드를 압축 결과에 저장
            enc[ecnt] = endic[s];
            ecnt++;

            // 새로운 문자열 s+c를 사전에 추가
            endic.insert({s + c, dcnt});
            dedic.insert({dcnt, s + c});
            dcnt++;
            // 현재 문자열을 c로 초기화
            s = c;
        }
    }

    // 마지막에 남아 있는 문자열의 코드를 저장
    enc[ecnt] = endic[s];                           // 마지막에 남아 있는 문자열의 코드를 저장
    ecnt++;

    dcnt--;                                                 // 실제 사전 항목 개수로 조정

    // 기본 사전만 출력 (다중 문자 항목은 출력 안 함)
    cout << basic_dcnt << endl;
    out << basic_dcnt << endl;

    // 생성된 사전 출력
    for(int i = 1; i <= basic_dcnt; i++) {
        cout << i << " " << dedic[i] << endl;
        out << i << " " << dedic[i] << endl;
    }

    ecnt--;              // 실제 압축 코드 개수로 조정

    // 압축된 코드 출력
    for(int i = 1; i <= ecnt; i++) {
        cout << enc[i] << " ";
        out << enc[i] << " ";
    }

    cout << endl;
    out << endl;

    in.close();  out.close();
}

코드는 크게 두 단계로 나뉜다. 첫 번째는 기본 사전을 만드는 과정으로, 파일을 한 번 순회하며 등장하는 개별 문자들을 모두 endic(문자열→코드)과 dedic(코드→문자열)에 등록한다. 이때 등록된 개수가 basic_dcnt이며, 이는 나중에 복원할 때 최소한으로 원래 사전을 다시 만들기 위한 기본적인 정보로 함께 저장해둔다.

두 번째는 실제 압축 단계다. 파일을 처음부터 다시 읽으면서, 지금까지 누적된 문자열 s 뒤에 새 문자 c를 붙인 s+c가 사전에 이미 존재하는지 검사한다. 존재한다면 s를 계속 확장하고, 존재하지 않는다면 그 시점까지의 s에 해당하는 코드를 출력한 뒤 s+c를 새로운 항목으로 사전에 등록하고 s는 c로 초기화된다. 이 반복은 루프 안에서 사전에 없는 문자열을 만났을 때만 코드를 출력하는 구조이기 때문에, 파일을 다 읽고 나서 마지막에 남아있는 s 하나는 별도로 출력해줘야 한다.루프 조건상 마지막 문자열은 항상 사전에 존재하는 상태로 남아있기 때문에, 자연스럽게는 출력될 기회가 없다 결과적으로 인코딩된 파일에는 기본 사전과 압축된 코드열이 함께 저장된다.

이 방식 역시 무손실 압축이므로, 사전 정보만 있다면 원본을 그대로 복원할 수 있다. 디코딩 코드를 보자.

#include <iostream>
#include <fstream>
#include <string>
#include <map>
using namespace std;

map<int, string> dedic;     // 복원을 위한 코드 → 문자열 사전

int main(){
    ifstream in("lzwencoded.txt");       // 압축 파일
    ofstream out("lzwdecoded.txt");      // 복원 파일

    int basic_dcnt;
    in >> basic_dcnt;

    for(int i = 1; i <= basic_dcnt; i++){                                         // 생성된 기본 사전
        int num;
        string word;
        in >> num >> word;
        dedic.insert({num, word});
    }

    int dcnt = basic_dcnt + 1;                  // 다음에 추가될 사전 번호

    int code;
    string prev;

    if(in >> code){                              // 첫 코드는 무조건 기본 사전에 존재
        prev = dedic[code];
        cout << prev;
        out << prev;
    }

        while(in >> code){
        string entry;

        if(dedic.find(code) != dedic.end()){
            entry = dedic[code];                 // 코드가 이미 사전에 있는 경우
        } else {
            entry = prev + prev[0];              // KwKwK 예외 상황
        }

        cout << entry;
        out << entry;

        dedic.insert({dcnt, prev + entry[0]});   // 새 사전 항목 추가
        dcnt++;

        prev = entry;
    }
    cout << endl;
    in.close();
    out.close();
}

디코딩은 인코딩의 역순으로 진행된다. 먼저 파일에 저장해둔 기본 사전을 읽어들여 dedic을 복원한다. 첫 번째로 읽는 코드는 항상 기본 사전에 존재하는 값이므로 그대로 출력하고 prev에 저장해둔다.

이후부터는 코드를 하나씩 읽으면서, 그 코드가 이미 사전에 있으면 해당 문자열을 그대로 꺼내 출력한다. 만약 사전에 없다면, 이는 인코더가 방금 새로 등록한 코드를 디코더가 아직 만들지 못한 경우인데, 이때는 직전 문자열 prev에 그 첫 글자를 붙인 문자열(prev + prev[0])을 대신 사용한다.흔히 KwKwK 예외라고 부르는 상황으로, 인코더가 사전에 방금 추가한 문자열을 바로 다음 코드로 사용해버릴 때 발생한다 그리고 매 반복마다 prev + entry[0]이라는 새로운 항목을 사전에 추가해주는데, 이는 인코더가 압축 과정에서 사전을 확장하던 규칙과 정확히 동일하다. 이렇게 인코더와 디코더가 같은 규칙으로 사전을 나란히 동기화해나가기 때문에, 전체 사전을 따로 전송하지 않고도 압축과 복원이 모두 가능해진다.
