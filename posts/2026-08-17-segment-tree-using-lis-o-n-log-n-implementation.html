세그먼트 트리를 활용한 LIS O(N log N) 구현

2026.08.17 세그먼트 트리 C++

최장 증가 부분 수열(LIS)은 이분 탐색으로 $O(N \log N)$에 풀 수 있지만, 세그먼트 트리를 쓰면 같은 복잡도로 더 많은 변형 문제에 대응할 수 있다.예를 들어 "각 원소가 LIS에 포함될 수 있는가" 같은 질의는 이분 탐색 풀이로는 바로 답하기 어렵다. 이 글은 값 좌표압축 위에 max 세그먼트 트리를 얹는 표준 구성을 정리한다.

아이디어

수열 $a_1, \dots, a_N$에 대해 $f(i)$를 $a_i$로 끝나는 LIS의 길이라 하면 다음 점화식이 성립한다.DP 상태 정의 연습에서 다룬 논증과 같은 구조다 — 끝점을 고정해 부분 문제로 쪼갠다.

$$f(i) = 1 + \max_{j < i,\; a_j < a_i} f(j)$$

$\max$ 부분을 "값이 $a_i$보다 작은 구간의 최댓값 질의"로 바꾸면, 값을 인덱스로 쓰는 세그먼트 트리로 각 $i$를 $O(\log N)$에 처리할 수 있다.

prefix maximum

구현

#include <bits/stdc++.h>
using namespace std;

struct SegTree {
    int n; vector<int> t;
    SegTree(int n) : n(n), t(2 * n, 0) {}
    void update(int i, int v) {
        for (t[i += n] = max(t[i + n], v); i > 1; i >>= 1)
            t[i >> 1] = max(t[i], t[i ^ 1]);
    }
    int query(int l, int r) {          // [l, r)
        int res = 0;
        for (l += n, r += n; l < r; l >>= 1, r >>= 1) {
            if (l & 1) res = max(res, t[l++]);
            if (r & 1) res = max(res, t[--r]);
        }
        return res;
    }
};

int main() {
    cin.tie(nullptr)->sync_with_stdio(false);
    int n; cin >> n;
    vector<int> a(n), s(a);
    for (auto &x : a) cin >> x;
    s = a;
    sort(s.begin(), s.end());
    s.erase(unique(s.begin(), s.end()), s.end());

    SegTree st(s.size());
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int v = lower_bound(s.begin(), s.end(), a[i]) - s.begin();
        int f = st.query(0, v) + 1;    // a[i]보다 작은 값들 중 최대 f
        st.update(v, f);
        ans = max(ans, f);
    }
    cout << ans << '\n';
}

핵심은 query(0, v)가 점화식의 $\max$를 정확히 담당한다는 것.같은 값이 여러 번 나올 때 query(0, v)처럼 반열린 구간을 쓰면 "strictly increasing" 조건이 자동으로 지켜진다. 좌표압축은 Codeforces 기출에서도 자주 쓰이는 기본기다.
